Setiap Kartu Halio dan laporan LAPSUS ditandatangani Ed25519 oleh server satuan. Seret berkasnya ke sini: bila satu byte saja berubah, buktinya ditolak. Kartu yang dikirim ulang lewat WhatsApp biasanya kehilangan tanda tangannya; kirim sebagai dokumen untuk mempertahankannya.

Seret Kartu Halio (.png) atau laporan (.json) ke sini
atau ketuk untuk memilih berkas

Kode: backend/halio/crypto_sign.py, CLI: python -m halio.verify berkas.png.
