# Peta Dokumen Halio

Semua dokumen ada di folder ini. Tabel di bawah menjelaskan isi dan status tiap dokumen, supaya pembaca tahu mana rujukan terkini dan mana catatan bertanggal.

- **Rujukan**: menggambarkan keadaan sekarang dan dijaga tetap mutakhir.
- **Bukti**: hasil uji pada tanggal dan build yang disebut di dalamnya.
- **Catatan bertanggal**: rencana dan riset saat ditulis. Angka di dalamnya adalah riwayat, bukan keadaan sekarang.
